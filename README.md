## 🚀 1-Click Publishing to GitHub

```bash
git init
git add .
git commit -m "feat: AI Tools Lab 8-agent autonomous YouTube production studio"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/ai-tools-lab-crew.git
git push -u origin main
```

Add your secrets in GitHub repo: **Settings > Secrets and variables > Actions**:
- `GEMINI_API_KEY`: Free from [Google AI Studio](https://aistudio.google.com/)
- `WHATSAPP_PHONE`: Your WhatsApp number with country code (e.g. `+1234567890`)
- `CALLMEBOT_API_KEY`: Free from CallMeBot on WhatsApp
